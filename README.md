# NEON DODGE — COMPLETE EDITION

A lightweight arcade survival game playable on **PC + Mobile** with one codebase.

## Run in VS Code
1. Open this folder in VS Code.
2. Install **Live Server**.
3. Right-click `index.html` → **Open with Live Server**.
4. No npm/build step is required.

## Mobile
Run Live Server on the PC and open `http://YOUR-PC-IP:5500` on a phone connected to the same Wi-Fi.

## Controls
- PC: WASD / Arrow Keys
- Pause: P / Esc
- Mobile: touch + drag anywhere on the arena

## Included features
- 5 enemy types: Hunter, Fast, Dasher, Splitter, Orbiter
- 5 power-ups: Shield, Slow, Magnet, 2X Score, Phase Shift
- 5 events: Neon Storm, Red Alert, Energy Rain, Time Freeze, Blackout
- Dynamic phases: Training, Rush, Chaos, Overdrive
- Combo scoring and dynamic difficulty
- Main menu, How to Play, Settings, Pause, Game Over, Statistics
- Personal best, longest survival, best combo, energy, enemies and games statistics
- Local achievements with unlocks
- Web Audio API effects with no external audio files
- Screen shake, particles, glow and responsive neon visuals
- Fullscreen-ready browser layout, safe-area support and no scrolling/zooming
- Low/medium/high graphics, reduced motion and high contrast options
- LocalStorage save system
- PC + Android + iPhone browser support
- No fake online leaderboard


## Difficulty pacing
Enemy speed increases gradually with survival time at a moderate rate, keeping the challenge fair on both PC and mobile.
